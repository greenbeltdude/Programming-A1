# Naive Bayes Text Classifier

## Overview

This Java coursework project implemented a Naive Bayes classifier for distinguishing between categories of text documents. 
The program combined multiple cooperating classes for word-frequency tracking, model training, 
classification, performance evaluation, and file-based input and output.

## Technical focus

- Object-oriented and modular program design
- Naive Bayes classification
- Word-frequency and probability calculations
- File reading and writing
- Classification evaluation using a confusion matrix
